# Transmission Map — How Shocks Propagate

Causal chains worth tracing explicitly. These are *hypotheses to test against the
measured data*, never conclusions to assert. Each link can break, and a broken
link is more informative than an intact one.

## Treasury debt management → metals
```
Long-bond buybacks / bill-heavy issuance
  → duration removed from the market, long-end yield suppressed
  → real yields fall relative to where they would clear
  → USD softens as rate support weakens
  → gold and BTC bid (debasement expression)
  → silver follows gold but lags if industrial demand is soft
```
Check: is the long end falling *while* issuance is heavy? That combination is the
repression fingerprint — ordinarily heavy supply lifts yields.

## Fed policy → metals
```
Dovish surprise → real yields fall → gold up, USD down
Hawkish surprise → real yields rise → gold down, USD up
```
Break case: if gold rises on a hawkish surprise, the market is pricing a policy
*mistake* or a credibility problem, not the rate path. That is a materially
different and more bullish regime for gold, and worth flagging loudly.

## Fiscal deterioration → term premium
```
Larger deficits / debt-ceiling brinkmanship
  → term premium rises (long yields up, curve steepens bearishly)
  → if the currency falls at the same time, it's a confidence event
  → if the currency rises, it's an ordinary rate-differential move
```
The **currency's direction is the discriminator** between a boring supply story
and a genuine loss-of-confidence story.

## Central bank reserve diversification → gold
```
Sanctions risk / reserve confiscation precedent
  → official sector diversifies out of the reserve currency
  → sustained, price-insensitive gold buying
  → gold decouples from the real-rate relationship
```
This is the main structural reason gold can rise with real rates rising. Official
buying is slow, persistent, and does not care about technical levels.

## Liquidity events → everything correlates
```
Funding stress / margin calls
  → indiscriminate selling, including gold (raise cash from what's liquid)
  → correlations across all risk assets go to 1
  → gold falls with equities *briefly*, then recovers first
```
Gold falling with stocks is usually a liquidity signature, not a repudiation of
the gold thesis. Distinguish by duration: days, not weeks.

## Industrial cycle → silver, copper
```
Manufacturing / solar demand strengthening
  → silver industrial demand rises → gold/silver ratio falls
Manufacturing weakening
  → silver lags gold → gold/silver ratio rises
```
Copper is the cleaner industrial read; copper/gold is a useful growth-versus-
debasement barometer.

## Crypto's two regimes
```
Risk-on liquidity regime: BTC correlates with SPX/NDX, behaves like high-beta tech
Debasement regime:        BTC correlates with gold, behaves like a monetary asset
```
Determine which regime is active from the *measured* 30-day correlations before
interpreting any BTC move. Asserting "BTC is digital gold" when its correlation
to SPX is 0.7 and to gold is 0.1 is exactly the kind of error this system exists
to prevent.

## Rate-move interpretation
A yield can rise for opposite reasons:
- **Growth/inflation expectations up** → breakevens rise, equities tolerate it
- **Term premium / credit concern up** → real yields rise, currency falls, equities dislike it
Decompose using `T10YIE` (breakeven) versus `DFII10` (real). Same nominal move,
opposite implications for gold.
